# 제품 범위

[한국어](product-scope.md) · [English](../en/product-scope.md)

BIS 우려거래자 자료를 정기적으로 수집하고 이름으로 찾아 원본과 검색 결과를 내려받는 업무 도구다. 사용자가 지정한 공개 BIS DPL·Entity List만 현재 수집 대상으로 삼는다.

## 화면과 사용자

업무 사이드바는 항상 표시한다. 접기·펼치기 버튼과 자동 숨김은 제공하지 않는다.
상단 경로는 사이드바의 대분류와 현재 페이지명으로 표시한다(예: 운영 관리 / 사용자 관리). 본문 제목 위에는 별도 공통 설명 문구를 반복하지 않는다.
업무 화면의 제목 옆·사이드바 하단·본문 하단에 출처 문구를 반복하지 않는다. 출처는 검색 결과의 DPL/Entity List 구분과 수집 관리·상세의 기관명, 원본 링크, 수집 시각으로 제공한다.

| 메뉴 | 기능 |
| --- | --- |
| 우려거래자 검색 | 이름·별칭·유사 후보, 출처/국가/정렬/페이지, 상세와 CSV |
| 내 검색 이력 | 검색어·조건·당시 버전 재실행, 개별/전체 삭제 |
| 우려거래자 수집 관리 | 출처별 최근 확인·성공·다음 예약·행 수·주소와 경고, 수동 수집 |
| 수집 이력 | 상태·단계·추가/제외/유지·검증 문제·보류 결과 반영, 결과 보기에서 원본 다운로드 및 해당 버전 조회 |
| 내 계정 | 비밀번호 변경 |
| 사용자 관리 | 운영 책임자만 계정 생성·활성/비활성·임시 비밀번호 발급 |
| 감사 이력 | 운영 책임자만 행위자·작업·기간으로 조회 |

운영 책임자는 환경 변수로 고정한다. 역할 편집 화면은 없다. 일반 사용자는 수집·조회·내려받기를 동일하게 수행한다. 임시 비밀번호는 최초 접속 시 변경해야 하며 변경·초기화·비활성화하면 기존 세션을 모두 종료한다. 다른 사람의 검색어는 운영 책임자도 조회하지 못한다.

## 수집 정책

수집 중에는 데이터 수집 버튼 내부에 회전 표시와 ‘수집 중’을 보여주고 버튼을 비활성화한다. 종료 후에는 ‘데이터 수집’으로 돌아온다. 실행 상세는 수집 이력에서 확인한다.

매주 월요일 오전 9시(Asia/Seoul)에 확인한다. 다음 예약을 DB에 저장하며 서버가 꺼져 놓친 예약은 재기동 후 한 번 수행한다. 수동 수집도 제공한다. 매 실행마다 BIS 안내 페이지에서 해당 문단의 다운로드 링크를 탐색한다. 안내·다운로드·최종 리다이렉트 주소와 해시를 기록한다.

공식 HTTPS 호스트와 파일 스키마를 통과한 새 주소는 자동 반영한다. 주소를 특정할 수 없거나 스키마가 맞지 않으면 실패 이력을 남긴다. 304/체크섬으로 중복 반영을 피하고 원본은 보관한다. 출처별 실행 잠금으로 동시 수집을 막는다. DPL과 EL은 각각 성공/실패하며 하나가 실패해도 다른 출처의 갱신은 가능하다.

검증 결과는 파일 구조와 필수 이름만 다룬다. 필수 이름이 비어 있는 행은 안전한 오류 코드·행 번호와 원본 파일로 확인하며 해당 파일 전체를 반영하지 않는다. 국가·날짜의 선택적 변환 실패는 검증 오류나 경고로 집계하지 않고 원문을 보존한다. 행 수가 직전보다 30% 넘게 줄면 별도의 반영 보호 정책으로 보류하고 운영 책임자가 확인 후 반영한다.

검증 정책 변경 전 수집 이력은 당시 결과를 유지한다. 새 정책이 적용된 첫 수집은 파일이 같아도 다시 처리하며, 이후에는 같은 파일과 같은 처리 버전의 중복 반영을 건너뛴다.

## 검색 정책

원문을 바꾸지 않고 별도 검색용 이름을 정규화한다. 공백·대소문자·구두점·악센트 차이와 단어 순서를 처리하고 PostgreSQL trigram으로 유사 후보를 찾는다. 기본 결과와 유사 결과를 함께 또는 따로 볼 수 있다. 한글 검색은 명시적으로 등록된 사전 범위에서 확장한다. 임의 기업명 자동 음역은 제공하지 않는다.

기업 이름으로 원본 행을 합치지 않는다. 완전히 같은 행만 화면에서 중복 수와 함께 묶는다. 점수는 이름 유사도이며 동일 기업이나 제재 대상이라는 결론이 아니다. 검색 결과·상세·내려받기는 조회한 원본 버전으로 고정한다. 검색 이력은 본인이 삭제할 때까지 유지한다.

최근 검색어는 검색창 아래에 비어 있지 않은 서로 다른 검색어 최대 5개를 회색 텍스트로 표시한다. 클릭하면 현재 화면 조건으로 최신 데이터를 재검색한다. ×를 누르면 본인의 같은 검색어 이력을 중복 기록까지 삭제하며, 이력이 없으면 영역을 숨긴다. 결과에서 유사도 숫자는 숨기지만 정렬에는 사용한다. 수집 카드의 최근 데이터 변경일은 내부 버전 번호 대신 현재 스냅샷 생성 시각을 표시한다. CSV는 검색·내부 지표 대신 한글 이름의 원본 필드로 구성한다. 세부 사항은 API 계약을 참고한다.

## 제외

거래 데이터 업로드/집계, 거래 상대방 심사·판정, 역할 관리, 다른 기관의 목록, 자동 법률 판단은 제외한다. 기존 DB와 과거 마이그레이션은 보존하며 해당 업무 API는 제거한다. 다중 API 인스턴스, 외부 알림, 원본 자동 삭제 정책은 현재 지원 범위 밖이다.
