# 문서 언어와 한국어 화면 기준

2026-09-10에 확인한 TradeOps Hub의 문서 관리 방식을 정리한 참고 문서입니다. 기준은 로컬 `C:\dev\tradeops_hub\AGENTS.md`의 `Documentation languages and Korean UX`와 `PROJECT_GUIDE.md`의 `Documentation entry points`입니다. 원격 확인 경로는 [TradeOps Hub 지침서](https://github.com/yrumupusm/tradeops_hub/blob/main/AGENTS.md)입니다. 원격 페이지와 작업 중 로컬 문서는 갱신 시점이 다를 수 있습니다.

## TradeOps Hub에서 사용하는 방식

| 구분 | 기준 |
| --- | --- |
| 공개 README | 한국어 독자를 위한 서비스 소개·실행·검증·구조·문서 안내 |
| 공개 설명 문서 | `docs/ko/`를 기본으로 연결 |
| 구현·검증 참고 문서 | `docs/en/` 우선 참고 |
| AI 작업 지침 | `AGENTS.md`, `PROJECT_GUIDE.md`, `tasks/todo.md`는 영어 유지 |
| 문서 대응 | `docs/ko/<path>`와 `docs/en/<path>`에 같은 상대 파일명 사용 |
| 문서 입구 | `docs/README.md`에서 언어별 문서 쌍을 연결 |
| 변경 관리 | 설계·API·운영 변경은 한·영 문서를 같은 커밋에서 갱신 |

두 언어 문서는 같은 설계와 구현 상태를 설명합니다. 번역 시 제약, 예시, 완료 여부와 과거 ADR의 맥락을 유지합니다. 내용이 다르면 코드·테스트·사용자의 최신 요구사항을 확인해 두 문서를 함께 고칩니다. 영어 문서를 참고한다는 이유로 사용자 의도를 바꾸지 않습니다.

## 한국어 화면 규칙

- 메뉴, 입력 안내, 오류, 알림, CSV 제목은 자연스러운 한국어로 씁니다.
- 날짜·숫자는 한국어 사용자가 읽기 쉬운 형식으로 표시하고 시간대를 명확히 합니다.
- 코드 식별자, API 경로, 설정 변수 이름, C4·ADR 같은 표준 명칭은 원형을 유지합니다.
- 원문 이름과 데이터는 보존합니다. 원본 레코드를 자동 번역하거나 내용을 바꾸지 않습니다.
- 구현 문서가 영어여도 사용자 화면을 영어로 만들지 않습니다. 영문 문서에도 실제 한국어 UI 문구를 그대로 인용할 수 있습니다.

법령 검색에 적용할 때에도 법령명·조문 번호·원문 내용을 임의로 번역하거나 다듬지 않습니다. 상태 코드의 한국어 표시와 법령 원문의 수정은 다른 작업입니다.

## 이 저장소에 이번에 적용한 범위

README를 한국어 소개 → 실행 → 검증 → 아키텍처 → 설계 문서 순서로 정리했습니다. 상세 환경 설정과 운영 절차는 [운영 안내](runbook.md)로 옮겼고, API와 검색 구조 설명은 기존 문서로 연결했습니다. 초기 H2 중심 설명과 현재 PostgreSQL·Qdrant 구성을 구분하고 분야 선택 요청 및 일반 화면에서 숨긴 진단 패널에 관한 오래된 README 표현을 정리했습니다.

이 저장소의 전체 문서를 `docs/ko/`, `docs/en/`으로 옮기거나 번역하는 작업은 아직 수행하지 않았습니다. 기존 문서 경로와 AI 지침 언어는 유지합니다. 전체 구조를 적용할 때는 문서별 언어 쌍을 만들고, README·문서 간 링크·테스트의 경로를 함께 수정한 뒤 누락·링크·내용 대응을 검증해야 합니다. 폴더만 만들고 번역을 완료한 것으로 표시하지 않습니다.
